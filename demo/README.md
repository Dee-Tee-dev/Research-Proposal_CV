# Interactive demo

Open `index.html` in a browser (or publish the `demo/` folder as a static site). It provides image selection/upload, qualitative model comparisons, and an interactive summary of the measured quartile gaps. No Python installation is needed for this browser-only demo.

For live inference with the pretrained models, install the project requirements and run `python app.py` from the repository root; this launches the full Gradio interface.
